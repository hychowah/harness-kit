# Project page

A project's map is `docs/index.html`. It uses the same page shape as this repo's site and loads `../harness-kit/docs/site.css`. `protocols/docs.md` tells the reader subagent to keep the tags and rewrite the sentences. `check` still prints `docs.reader` or `docs.map`.

`compatible`. An older sealed session still passes `check` for links and the seal. It is graded only when its stamp is this commit. Nothing already sealed has to be edited. A new session that owes the map fails `docs.reader` or `docs.map` until `docs/index.html` is the reader return and is no longer the template page.
