# Commit when asked

Development is plan, then implement, then commit. Implement writes the files, the log, and the Last closed pointer, and it runs the gate. It does not commit. Commit only when the user asks or the prompt says to commit. That commit is the version. `AGENTS.md` is the rule. The generated block says the same sentence, so a project agent reads it before any kit file.

`compatible`. An older session file still passes `check` for links and the seal. It is graded only when its stamp is this commit. Nothing in `project/`, `plans/`, or `sessions/` has to be edited.
