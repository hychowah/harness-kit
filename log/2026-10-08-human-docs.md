# Human docs

A project explains itself in `project/ARCHITECTURE.md`. `protocols/docs.md` is the writing rule. A subagent, framed as a teammate who has not read the code, rewrites the draft. The shipped file is that return. The website links the protocol and follows the same writing rule.

`compatible`. An older sealed session still passes `check` for links and the seal. It is graded only when its stamp is this commit. Nothing already sealed has to be edited. A new session that owes a reader fails `docs.reader` or `docs.map` until that return is in place.
