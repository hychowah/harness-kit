# Owning session

A product commit is owned by one session. `writes` is the exact product files in that commit. It starts empty. `close-session --from-diff` sets it from the product diff, seals the session, and stages that record. While the tree is dirty, `check` wants one open session. The hook wants one session closed in the index and not closed at `HEAD`, with `writes` equal to the staged product paths. An open plan covers nothing. A directory covers nothing. A coding session closes on `design.md`, `review.md`, and `verify.md`, and on one handoff body when `writes` is not empty. The live human file must equal exactly one graded return.

`breaking`. `check` fails `coverage.gap` for a product diff that an open plan prefix used to cover. `plan.blank`, `plan.overlap`, and `session.outside` are gone. A sealed session that has no `design.md` and no `review.md` keeps its seal. `upgrade` does not edit `project/`, `plans/`, or `sessions/`. Close or abandon any open session before moving the pin. The `agent-skill` pointer records the `program-phase` parent. That pointer does not change the grade. A new session id is the day plus the feature slug. A bare feature name is not the id. An existing session id is left as it is.
