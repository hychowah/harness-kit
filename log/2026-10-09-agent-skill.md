# Skill set submodule

`agent-skill/` is a submodule at the root of this repo. The parent records that commit. `clone_kit`, `sync`, and `upgrade` check out that same commit when the directory is missing or empty. A directory that already has a different commit crashes and is not replaced. `check` crashes if that HEAD is missing or is a different commit. The message names `agent-skill` and the recorded commit. It is not a check result row.

`compatible`. An older sealed session still passes `check` for links and the seal. It is not graded again under this rule. A kit checkout whose `agent-skill` commit is missing or different crashes before that grade. `upgrade` or `sync` checks out the recorded commit when the directory is missing or empty.
