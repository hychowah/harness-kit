# Domain law

This file is the project's law. The harness kit must not gain rules that are only true here.

Write the vocabulary, sources, and done-conditions that belong to this project.

This file decides whether a turn is kit work. A turn it does not mark is not kit work. Open only the law named for that turn, and do not open a kit file.

Kit work is a turn whose product is a plan, a session, or a move of the kit submodule. For that turn the kit owns the class table, plan and session links, worker write paths, the document and coding packs, and `harness.py check`.

A turn this project claims for itself is not kit work. Name that law in this file.
