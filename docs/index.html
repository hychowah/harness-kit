Phaseaudit

Grade the claims

The auditor reads the brief, the handoffs, the write paths, and gaps.md. They write audit.md. The gathered files stay as the gather left them. Unsupported claims are listed, then fixed or written up as gaps.

needs brief.md and audit.md
Sealsclosed

Seal, then the next question is a new session

close-session seals the files. As the session closes, the gap rows are summarized into project/gaps.md.

A claim in a gathered file or a report stands when the session cites a source path the brief named, when the operator stated it and the text says so, or when it is copied from a path the plan already lists. Anything else is a gap. The report leaves the gap as a gap.

Sources that disagree stay side by side. One session has one report writer. The report path, when there is one, sits under project/reports/ or on another path already listed in writes.

The session that writes the artifact is a different seat from the session that grades it. On this pack the grade is audit.md.

Parent and workers

The parent classifies the turn, names every write path, and merges. A worker returns paths, coverage, and gaps. The shape of the handoff is exemplars/handoff.md, written to sessions/<id>/handoffs/<worker>.md.

Parentthis session

Name the paths, then merge

  • Objective, in one sentence, with the plan id and the session path
  • Pack: the session's pack id
  • Exact project-relative write paths
  • The sources to read
  • When to stop
  1. Returnshandoffs/<worker>.md

    Worker

    Its own write paths. Coverage, gaps, conflicts, and what was opened. An empty search still writes the handoff, says empty, and adds a gap.

  2. Returnsa different path

    Another worker

    A second worker in the same session uses different write paths. The parent merges the two handoffs.

  • A spawn names its write paths. Paths under .harness/ are kit paths, so they stay off the list.
  • A worker finishes its own write paths and returns to the parent.
  • Write paths are relative to the project root and remain inside the project, outside .harness/.
  • A new document session reads the sources the plan lists, and sources it fetches into a path the session listed.

Pack graph

A pack is a graph in pack.json. The charts above are the shipped paths. A project may add project/packs/<id>/pack.json. Entering a node is the session protocol. Result lines are defined in scripts/checks.py.

The gate

harness.py check is the gate. It exits non-zero only on FAIL. WARN is printed and the process still exits 0. A dirty kit checkout crashes, and that message includes pin.dirty and uncommitted. It is not a result row. VERSIONING.md is that contract. link rebuilds project/links.json from the session files. Session files are the source of those edges. Patch the prose, then run link, when you want the index to catch up.

Checkpin

The checkout matches the pin

kit_commit must be this clone's HEAD. Anything else is FAIL pin.mismatch, and the graph is not graded. A dirty checkout crashes instead. kit_path is the clone this script is running from.

Moving the kit

A project takes a new procedure by checking out a commit that already exists. The version is that commit. upgrade rewrites .harness/pin.json and the generated block in AGENTS.md. Plans, sessions, and project/LAW.md stay as they are. harness_commit on a session already created stays as it was.

Words used on this page

Kit
This repository, cloned into a project at .harness/kit.
Project
The repository that holds facts, plans, sessions, and code.
Pack
A graph of work nodes in pack.json. This kit ships document and coding as two single-path graphs. A project may add project/packs/<id>/pack.json in the same shape.
Plan
A named piece of work in plans/<id>/, open until close-plan.
Session
One pass over one plan, in sessions/<id>/.
Phase
The session's cursor. The pack names the nodes.
Preflight
A report of whether a node can be entered. It does not move the cursor.
Write path
A project-relative path the session may change.
Gap
A fact the sources did not support, written down instead of invented.
Gate
harness.py check. Exit 0 means no FAIL. WARN does not fail the process.
Pin
.harness/pin.json: kit path, remote, and commit hash.
Fingerprint
The seal on a closed session. KERNEL.md names the bytes it covers.
Worker
A helper given its own write paths. It returns to the parent, who merges and assigns any further work.
Depth
low, medium, or high, set on the plan and copied onto the session.
